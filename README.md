# ✨ Overview

English Master is a modern Android application designed to help learners improve every aspect of English—from vocabulary and grammar to pronunciation and conversation.

Whether you're a beginner or preparing for international exams, the app adapts to your progress and delivers personalized learning experiences powered by AI.

# 🏗 Architecture

```
Presentation
│
├── Jetpack Compose UI
├── ViewModels
└── Navigation

        │

Domain
│
├── Use Cases
├── Business Logic
└── Models

        │

Data
│
├── Repository
├── Local Database
├── Remote API
└── AI Services
```

Built using a clean and scalable MVVM architecture.
